Chapters unlock as you molt. Locked text is not a spoiler wall. It is a reminder to go do the work. Open notes link the exact bench. They do not carry answers.

0 · Hello

View source. Follow comments. Cicada's first JPEG was a surface. The interesting part was never the pixels you were meant to admire.

Dig deeper

A static file is still a file when nobody links it. Comments are a teaching channel, not a leak. If a page says almost nothing, the author is asking you to look beside it.

I · Classical ciphers

Atbash, Caesar, ROT13, Vigenere, A1Z26. The 2012 thread used inversion then a Vigenere keyed by Tiberius Claudius Caesar (U for V). Frequency analysis still works on long Caesar. It fails on a short Vigenere. That is the lesson.

Dig deeper

Atbash is a mirror. Caesar is a rotation. Vigenere is a rotation that changes with each letter. When the key is an emperor's name, the history is the instrument. Watch the frequency bars on a long Caesar, then on a short Vigenere: the first still has a hill, the second looks flatter.

II · Book ciphers

Coordinates into a shared volume. Fetch the file. Count from 1. Strip punctuation after you land on the word. Cicada used scripture, poetry, and later their own rune book as the volume.

Dig deeper

The ciphertext has no entropy of its own. If you do not hold the same edition, the coordinates are noise. Line:word is kind. Page:word is historical. Always fetch. Never trust a paraphrase.

Open the book bench

III · Steganography

OutGuess (1999) hides data in JPEG DCT coefficients with statistical cover. LSB in PNG is the classroom cousin: last bit of a channel, stop at 0x00. Always also run strings. A declared file format can have a tail.

Dig deeper

A bit-plane is that bit drawn as a picture. Bit 0 of red is where classroom messages like to live. Higher planes look like the original. Strings will catch a tail that LSB will not. Both habits belong in the same hour.

Open the LSB bench

IV · Spectrograms

Time on X, frequency on Y, energy as brightness. Audacity, Sonic Visualiser, or a short-time FFT. Cicada wrote words in the heat of a WAV. Lyrics were a decoy if they existed at all.

Dig deeper

Larger FFT: finer pitch, worse time. Smaller hop: denser columns. If a letter is a smear, change the window. If it is a stack of tones, you are looking at a drawing, not a voice.

Open the spectrogram bench

V · Primes and toy RSA

n = p*q. e coprime to phi. d = e^-1 mod phi. c = m^e mod n. 3301 is prime; that was branding plus a filter. Real RSA is not factorable in a browser. This one is, so you can feel the inverse.

Dig deeper

The classroom path is: factor, invert, decrypt each block as an ASCII code point. Then forge a pair with two small primes so you see n and d born. Do not ship those primes. The lesson is the inverse, not the number.

Open the RSA bench

VI · Runes

Liber Primus uses a custom gematria. INSTAR uses Anglo-Saxon futhorc sound values and an original line. Unsolved pages stay unsolved. Do not invent a translation and call it a break.

Dig deeper

A custom gematria assigns numbers to runes so addition becomes a checksum or a second cipher. Cicada's table is public; many pages of Liber Primus are not solved. The bench here is phonetic only. Honesty is the tradecraft.

VII · Onions, PGP, and the ending

Cicada signed statements with PGP and published .onion URLs. A v3 onion is 56 characters of base32 plus .onion, derived from an ed25519 public key. PGP (or minisign, or signify) lets strangers check that a statement is still from the same key. INSTAR does not run a hidden service that pretends to hire you. If a stranger on the internet asks you to fly somewhere with a QR code, that is not this school.

You finished the public molts. There is still an unused door, if you treated the wing as a file and not only as a picture.

Dig deeper

Signatures are about continuity of a key, not virtue of a person. An onion is an address derived from a key, not a club. Sovereignty here means: verify, then decide. Do not follow a QR into a stranger's plan.

Open the hash bench if you want to see how this school locks a guess without storing it.

VIII · Page 56, read as a payload

Liber Primus page 56 printed a 512-bit hex dump and called it a hash of a deep-web page. The preimage is still unsolved. Do not invent a SHA-512, BLAKE, or Whirlpool inversion. The published work is a reading: first eight hex characters of each printed line, 160 bits, a v2 onion that died with Tor v2 in 2021-10. The leftover 352 bits are AES-256-GCM-shaped and unverified.

Dig deeper

A digest can be a lock (find a preimage) or a payload (read the bits as published). Page 56 still has no known preimage. The five-line wrap is load-bearing: 8x16 and 4x32 wraps do not yield the published host. SHA3-512 is an anachronism (FIPS 202 is 2015). Magnet, IPFS, Freenet, and I2P templates have been formatted; none resolve to known content. The next finite experiment is a local AES-256-GCM open of leftover-as-key-and-nonce against a blob you already hold - not a blob you invent, and not a live hidden service.
